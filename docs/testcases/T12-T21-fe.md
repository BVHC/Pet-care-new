# Test case FE — T12 (xác thực) và T21 (quản lý danh mục)

> Hợp đồng: `docs/api/identity-v1.md` (UC01–UC05), `docs/api/catalog-v1.md` #1–18 (UC28–UC31). Cập nhật 2026-10-09.
> Test tự động tương ứng ghi ở cột cuối mỗi bảng.

## 1. Chuẩn bị

**Chạy với mock (mặc định, không cần BE):** `cd FE && npm run dev`, rồi mở `http://localhost:5173`. Mock trả đúng path và envelope của hợp đồng (`FE/src/shared/api/mock/`).

| Tài khoản demo | Role | Dùng cho |
|---|---|---|
| `chuoi@petcare.vn` | SUPER_MANAGER | T21 — quản lý danh mục |
| `reception@store1.vn` | RECEPTIONIST | Kiểm tra bị chặn ở T21 |
| `doctor@store1.vn` | VET | Quên mật khẩu, email đã dùng |
| `khach@petcare.vn` | CUSTOMER | Đổi mật khẩu ở `/security` |
| `newstaff@store1.vn` | RECEPTIONIST, phải đổi mật khẩu | Bắt đổi mật khẩu lần đầu |

- Mật khẩu chung: **`Petcare123`**. Mock không gửi email, **mọi mã OTP là `123456`**.
- Đăng nhập nhanh: `http://localhost:5173/admin/login`, chọn tài khoản rồi bấm *Đăng nhập với vai trò…*. Đăng nhập thường: `/auth/login`.
- Đưa dữ liệu mock về ban đầu: DevTools → Application → Local Storage → xóa `petcare-mock-identity`, `petcare-mock-catalog`, `petcare-session` (hoặc gõ `localStorage.clear()` ở Console) rồi F5.

**Chạy với BE thật:** đặt `VITE_API_MOCK=false` trong `FE/.env`, chạy BE ở cổng 8081 (`VITE_API_URL=http://localhost:8081`). Mã OTP xem ở Mailpit `http://localhost:8025`. Giới hạn hiện tại của BE:
- Đăng ký, xác thực OTP và đăng nhập của **khách** trả 500 tới khi BE-2 có `CustomerApi` / `CustomerQueryApi` (nợ D001, D010). Nhân viên đăng nhập, quên / đổi mật khẩu bình thường.
- Chưa có API tạo nhân viên: tài khoản SUPER_MANAGER phải tự tạo bằng SQL (`docs/architecture/system-overview.md`).
- Tắt *Quản lý hạn dùng* của sản phẩm và xóa loại vaccine trả 500 tới khi có module kho (T18) và tiêm chủng (T28).
